# DETAILING LAB

Готовый статический сайт детейлинга Андрея. Все последние правки включены.

## Загрузка в GitHub

1. Распакуйте ZIP.
2. Загрузите содержимое архива в корень репозитория: index.html, style.css, app.js и папку assets. Не загружайте сам ZIP вместо файлов.
3. Сохраните изменения в репозитории.

## Деплой в Vercel

1. Импортируйте GitHub-репозиторий через Add New → Project.
2. Framework Preset: Other.
3. Root Directory: корень репозитория.
4. Build Command и Install Command оставьте пустыми. Output Directory: . (точка).
5. Нажмите Deploy.

Сборка и установка зависимостей не требуются.

## Файлы

- index.html — страница сайта.
- style.css — оформление и мобильная версия.
- app.js — услуги, цены и выбор способа связи.
- assets/ — фотографии и логотип.
